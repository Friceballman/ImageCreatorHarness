# Image Workbench

OpenAI Images APIを利用する、Windowsを主対象としたローカル画像制作ハーネスです。実装は仕様書と`AGENTS.md`に従って段階的に進めています。

## 開発環境

- Python 3.12以上
- `pip install -e .`で実行時依存を導入
- `pip install -e ".[dev]"`で開発用依存（pytestを含む）も導入

開発用仮想環境を使う場合は、リポジトリ直下で次のように作成できます。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

APIキーは`OPENAI_API_KEY`環境変数からのみ読み込みます。`.env`の自動読込はしません。`.env.example`は変数名の例であり、実際のキーを書き込まないでください。

## データとバックアップ

案件データと画像は`projects/`以下に保存します。バックアップ対象は`projects/`全体で、元画像、候補、JSON、イベント、レビュー、レポートを含めてください。別ドライブ等に定期コピーし、復旧時はアプリを停止して案件フォルダを同じ構造のまま`projects/`へ戻します。Gitだけをバックアップにせず、復旧前に現行フォルダを退避してください。現時点で`projects/`はGit除外していません。画像をGitへ登録しない運用にする場合も、上記の別媒体バックアップが必要です。元画像、候補画像、履歴は上書き・物理削除しません。`.env`、秘密情報、Pythonキャッシュ、ビルド生成物はGit除外です。

## 実装状況

現在、設定・案件・参照画像・要件・計画・候補・レビュー・採用版・監査レポート・Images API実行のCLIを実装しています。操作方法は`iwb --help`および各コマンドの`--help`を参照してください。
